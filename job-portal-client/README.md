# Job Portal Management System 🚀

A full-stack web application built with the MERN stack (MongoDB, Express, React, Node.js) that allows users to seamlessly browse, search, and apply for jobs.

## Features
* **Job Board Dashboard:** View available jobs dynamically fetched from the database.
* **Live Search:** Filter jobs by title or company instantly.
* **Job Posting:** Submit new job listings with descriptions and salary details directly to the database.
* **Application Management:** Apply for roles and view/withdraw applications in a dedicated user portal.
* **Modern UI:** Fully custom glassmorphism design utilizing a Midnight Mesh aesthetic.

## Tech Stack
* **Frontend:** React, Vite, CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JSON Web Tokens (JWT)

## How to Run Locally
1. Clone this repository.
2. Run `npm install` in both the frontend and backend directories.
3. Create a `.env` file in the backend with your `MONGO_URI` and `JWT_SECRET`.
4. Run `npm start` in the backend and `npm run dev` in the frontend.
